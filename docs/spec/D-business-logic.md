## PART D — CROSS-APP BUSINESS LOGIC: STATE MACHINES, BUTTON METHODS, COMPUTED FIELDS, INTEGRATIONS

All apps operate on ONE shared database: `res.partner` (customers/vendors/contacts/employees' private addresses), `res.users`, `res.company`, `res.currency`, `product.template`/`product.product`, `uom.uom`, `account.*`, `mail.*`. Every model with a chatter posts a message for every state change (system message text given below). Each button listed in Part E under `HEADER` maps to a method here. Where a method is not described, implement Odoo's standard behaviour (Odoo 17/18/19 semantics).
